# Meu Portfólio

Este é o meu primeiro portfólio como desenvolvedor, onde apresento um pouco sobre mim, minhas habilidades e meus projetos. Criado com dedicação para mostrar minha trajetória no mundo da tecnologia.  

## Seções do Portfólio  

- **Home:** Uma introdução com meu nome e minha área de atuação.
- **Sobre Mim:** Um pouco da minha história e jornada na tecnologia.
- **Tecnologias:** As principais linguagens, frameworks e ferramentas que domino.
- **Projetos:** Alguns dos trabalhos que desenvolvi, demonstrando minhas habilidades na prática.
- **Contato:** Links para me encontrar e trocar uma ideia sobre tecnologia ou oportunidades.

## Tecnologias Utilizadas

- **React** e **Next.js** para a estrutura do projeto.
- **Tailwind CSS** para estilização rápida e responsiva.
- **TypeScript** para um código mais seguro e escalável.
- **ShadCN** como biblioteca de componentes prontos e modernos.
- **Lucide Icons** para adicionar ícones ao design.
